# 产品截图

本目录存放 PeekView 产品界面截图。

## 截图清单

| 文件 | 说明 |
|------|------|
| `dashboard.png` | 主控制台界面 |
| `entry-detail.png` | Entry 详情页（含代码高亮） |

## 使用说明

截图通过 PeekView 发布后，可通过短链接 `/{slug}` 直接分享。
Markdown 中引用图片使用相对路径：`![描述](dashboard.png)`
